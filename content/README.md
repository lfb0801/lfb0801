# A terminal garden for unfinished thinking

I’m **Lloyd van Zaalen**. This is a small, read-only filesystem where I collect ideas, decisions, and project case studies about software engineering.

It is deliberately more workshop than showroom. Some files are finished; others are seeds worth returning to.

## Start here

- [about.md](/about.md) — the person behind the prompt
- [ideas/README.md](/ideas/README.md) — working notes and recurring questions
- [projects/README.md](/projects/README.md) — case studies without requiring repository access
- [contact.md](/contact.md) — ways to reach me, if something here starts a conversation

## The connecting thread

Java and backend design, GitLab delivery systems, refactoring education, and AI-assisted engineering may look like separate interests. To me, they meet in one question:

> How do we make engineering reasoning visible, durable, and easier to improve?

## Try the terminal

Run `help` for the complete command set. A good first walk is:

```text
ls
cd ideas
show README.md
clean
```

Nothing here reaches a real shell. The environment only understands a short, explicit list of commands and files.
